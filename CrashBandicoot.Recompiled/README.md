# CrashBandicoot.Recompiled (local only)

This folder is **gitignored** except for this README.

The **consumer launcher does not use this folder**. End users prepare the game into `%LocalAppData%\CrashBandicoot-Launcher\recomp\` automatically.

Developers iterating on RecompOne may still drop generated `Entry.cs` / `main.cs` here for ad-hoc experiments — do **not** commit those files (they derive from the retail executable).
