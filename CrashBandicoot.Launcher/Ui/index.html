About

Unofficial fan project — not affiliated with Sony, Activision, or Naughty Dog.

Unofficial tools for a disc you own. First prepare writes a game folder next to the exe — later Starts reuse that.

Prepared files never replace your dump: you still need a valid NTSC-U .cue + .bin (SCUS-94900) every time you play.
